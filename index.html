🚀 Git Exercise

Follow these steps to complete the lets-start-1 exercise. Each command has a Copy button.

Step 1 — Pull the latest version

Switch to the first branch and download the newest changes.

git checkout first
git pull

Step 2 — Create a new branch

Create a branch called lets-start-1.

git checkout -b lets-start-1

Step 3 — Edit the HTML file

Open your HTML file and change the page content so it simply says: 

lets-start-1

Step 4 — Stage the changes

git add .

Step 5 — Commit your work

git commit -m "changed text"

Step 6 — Push your branch

git push origin lets-start-1
🎉 Great job! Once you've completed all six steps, your branch will be uploaded to GitHub.
